# Security policy

Mini Meeting Minutes handles private conversations, so security reports are welcome and taken
seriously. How the app protects your meetings, and the limits of that protection, are described in
[Privacy and security](docs/PRIVACY-AND-SECURITY.md).

## Reporting a vulnerability

Please report vulnerabilities privately: on this repository's **Security** tab, choose **Report a
vulnerability**. Please don't open a public issue for something that could put people's meetings
at risk.

Especially welcome:

- any way audio could be written to disk, or kept longer than described;
- any network connection the app makes;
- sensitive details that get past redaction that's switched on;
- anything that could record before the person recording has confirmed that everyone agreed.

## Supported versions

Fixes go into the `main` branch. To pick them up, run the install line again: it updates your copy
and rebuilds it.
